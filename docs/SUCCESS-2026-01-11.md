## Das Problem (Lösung)

**Root Cause:** Brevo SMTP benötigt eine spezielle SMTP-Login E-Mail-Adresse (nicht die Absender-Adresse).

### Finale `.env` Konfiguration (funktioniert!):

```bash
SMTP_HOST=smtp-relay.brevo.com
SMTP_PORT=587
SMTP_USERNAME=die-brevo-anmelde-email@example.com  # WICHTIG: Brevo-Login-E-Mail!
SMTP_PASSWORD=brevo-smtp-key-aus-dashboard
SMTP_FROM_EMAIL=noreply@peterebenhoch.com
SMTP_FROM_NAME="Peter Ebenhoch Website"
TO_EMAIL=pe@peterebenhoch.com
```

**Key Insight:** Bei Brevo ist `SMTP_USERNAME` NICHT die Absender-E-Mail, sondern die E-Mail mit der man sich bei Brevo anmeldet!

## Technische Details

### Server-Setup
- **OS:** Ubuntu auf Hetzner
- **Webserver:** Caddy (mit automatischem HTTPS)
- **PHP:** PHP 8.1 + PHP-FPM
- **SMTP:** Brevo (300 E-Mails/Tag kostenlos)

### Finale Caddy-Konfiguration
```caddy
www.peterebenhoch.com, peterebenhoch.com {
    root * /var/www/peterebenhoch.com
    
    @php {
        path /api/*.php
    }
    
    handle @php {
        php_fastcgi unix//var/run/php/php8.1-fpm.sock
    }
    
    respond /api/.env 404
    file_server
}
```

### Wichtige Lessons Learned

1. **Caddy PHP-FPM Socket:** `unix//path` (mit Doppel-Slash!)
2. **Permissions:** Caddy User muss in `www-data` Gruppe sein
3. **Brevo SMTP:** Username ≠ Absender-E-Mail (Login-E-Mail verwenden!)
4. **Debug:** Eigene Log-Dateien schreiben wenn PHP-Logs nicht helfen
